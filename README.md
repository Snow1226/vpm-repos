## Neigerium VPM Repository
作成したツールのVPMリポジトリです。

### 導入手順
VRChat Creater CompanionまたはALCOMをインストールし、  
以下のリンクをクリックし、ADD to VCCを押してVPMリポジトリを追加してください。  
[VPM Repository](https://snow1226.github.io/vpm-repos/)  
  
なんらかの理由でADDボタンが押せない等発生した際は  
VCC/ALCOMのVPMリポジトリの追加から、以下のURLを入力し手動登録してください。  
[https://snow1226.github.io/vpm-repos/index.json](https://snow1226.github.io/vpm-repos/index.json)
